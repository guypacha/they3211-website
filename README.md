# אתר הקבוצה של The Y 3211

האתר של קבוצת הרובוטיקה FRC 3211 מירוחם. בנוי ב־[Astro](https://astro.build), בעברית (RTL), ומתפרסם אוטומטית ל־GitHub Pages בכל דחיפה ל־`main`.

## איך מוסיפים תוכן

- **רובוט חדש / עונה חדשה:** מעתיקים קובץ ב־`src/content/robots/` (למשל `2026.md`), משנים שנה, שם, מנגנונים ותוצאות, וכותבים כמה משפטים.
- **תמונה:** שמים את הקובץ ב־`public/photos/` (JPG או WebP, עד 300KB) ומוסיפים לקובץ הרובוט `photo: "/photos/<שם>.jpg"`.
- **טקסטים בעמודים:** בקבצים ב־`src/pages/`. פרטי קשר משותפים ב־`src/lib.ts`.
- **מגרש האימונים:** האפליקציה נמצאת ב־`public/train/app/index.html`.

## להריץ במחשב

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # בונה לתיקייה dist
```
